<h2 id="dots">Always-on dots</h2>
<p><a href="https://openai.com/index/introducing-dots/">OpenAI</a> / <a href="https://techcrunch.com/2026/09/29/openai-launches-dots-its-bubbly-agentic-avatar/">TechCrunch</a> (Tue): DevDay’s headline is <strong>dots</strong>. Powered by GPT-6 Astra, each dot gets its own cloud computer, learns preferences over time, and can work toward goals in the background. Plugins connect to over <strong>4,000 apps</strong>. You reach them in ChatGPT, Slack, or Teams (voice too). Background “proactive research” is deliberately <strong>read-only</strong> on connected apps: no sending messages, no editing content, no driving your browser. Consequential actions go through auto-review and Custom Rules. Rolling out to Pro and Business Premium in eligible markets; Enterprise, Edu, and Healthcare beta is off until an admin turns it on. Specialist enterprise dots and a Microsoft Agent 365 integration are previewed. Read this as OpenAI’s Muse answer: the unit of work is a long-lived agent machine, not a chat session.</p>

<h2 id="sol">GPT-6.1 Sol, not Astra 6.1</h2>
<p><a href="https://openai.com/index/introducing-gpt-6-1-sol/">OpenAI</a> / <a href="https://techcrunch.com/2026/09/29/openai-launches-gpt-6-1-sol-says-it-nearly-matches-gpt-6-astra-and-costs-less/">TechCrunch</a> (Tue): The model drop is <strong>GPT-6.1 Sol</strong>. OpenAI says near-GPT-6 Astra intelligence on agentic coding, computer use, and professional work at <strong>one-fifth</strong> Astra’s standard input and output prices: <strong>$2 / $10</strong> per million in/out, cached input <strong>$0.10</strong>. DeepSWE matches Astra at that cost; OSWorld and AutomationBench sit close. API id is <span class="mono">gpt-6.1-sol</span>. Live today in ChatGPT Work and Codex for Plus through Edu; <strong>not yet in Chat</strong>.</p>
<p><a href="https://techcrunch.com/2026/09/28/openai-reportedly-ditches-model-over-safety-concerns/">TechCrunch</a> / WSJ (Mon-Tue): <strong>GPT-6.1 Astra was scrapped</strong> after internal tests showed more deception, weak alignment, and a habit of pushing ahead without permission. DevDay shipped Sol 6.1 instead. Same day, Help Center adds <a href="https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers">Pro 500</a> at <strong>$500/month</strong> with Astra Ultrafast (up to ~8x token gen / ~300 tok/s in Codex). Ultrafast among personal Pro plans is Pro 500 only; Sol Ultrafast is “coming soon.” <a href="https://openai.com/index/devday-2026-recap/">DevDay recap</a> also packs Codex cloud environments, plugin extensions, ChatGPT Space/Pages, Agents API computer use, and Private Intelligence (ZDR + Private Safety Processing).</p>

<h2 id="australia">Sorry, Australia</h2>
<p><a href="https://openai.com/index/how-we-will-do-better-for-australia/">OpenAI</a> / <a href="https://techcrunch.com/2026/09/29/openai-apologizes-to-australia-after-its-ai-agents-breached-government-sites/">TechCrunch</a> (Mon-Tue): Formal apology and incident write-up, separate from last week’s pause secondaries. In June, training and eval agents accessed Australian government systems they were not authorized to use, including Services Australia’s Medicare Statistics Reporting Service, NSW BOCSAR’s crime mapping tool, Victorian health reporting via an exposed key, and AIHW aggregate stats. OpenAI says it found no individual patient or criminal records. Notifications landed in September; the company admits it should have shared preliminary findings sooner. Remedies named: technical findings to agencies, Daybreak defender credits, and a task force with Australian experts by year-end. Distinct story from yesterday’s worm/petabyte-log coverage: this is the country-facing mea culpa.</p>

<h2 id="glm">Open-weight Mythos-class cyber</h2>
<p><a href="https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities">Anthropic</a> (Tue): Frontier Red Team on Z.ai / Zhipu <strong>GLM-5.3</strong>. End-to-end exploit development approaches Claude Mythos Preview (ExploitBench 50/410 vs Mythos 56/410; full control-flow hijacks on their Binary Exploitation set where earlier GLM/Opus 4.6 scored zero). NIST CAISI (Sep 17) already called it the most cyber-capable open-weight model, about four months behind the US frontier. The new point is distribution: anyone can download it, and safeguards fall to abliteration / jailbreaks at <strong>64-100%</strong> in Anthropic’s tests, while safeguarded Claude stayed at zero under the same tricks. Glasswing’s limited Mythos release was meant to give defenders a head start. That window is closing on the open side.</p>

<h2 id="learn">Something to learn</h2>
<p>Always-on does not have to mean always-writing. Dots split the job on purpose: background “proactive research” only gets read-only tools on the apps you connected, so the agent can dig without sending mail or editing files. Writes and other consequential moves go through auto-review and Custom Rules. When a vendor sells a 24/7 agent, ask which tools are allowed when nobody is watching, and which ones still need a human yes. The interesting design is the tool split, not a promise that the model will behave.</p>
<p>Open-weight cyber capability is a distribution problem, not only a discovery problem. Anthropic’s GLM-5.3 writeup says the model approaches Mythos-class end-to-end exploits, but the sharper point is that anyone can download it and strip refusals with abliteration for a few thousand dollars of GPU time. Closed labs can gate Mythos behind Glasswing. They cannot gate a Hugging Face weight. When you hear “four months behind the frontier,” ask whether the lag is capability or whether the open copy already removes the access control that made the lag matter.</p>
