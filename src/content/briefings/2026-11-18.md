<h2 id="nvidia">Nvidia beats without Jensen</h2>
<p>Nvidia <a href="https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-Third-Quarter-Fiscal-2027/">reported</a> $115.8 billion in revenue for the quarter that ended Oct. 25, up 103% from a year ago and well above the $108 billion it had guided. Data center revenue was $107.6 billion. Earnings were $2.68 a share against the $2.47 Wall Street expected. On the <a href="https://stockanalysis.com/stocks/nvda/transcripts/739383-q3-2027/">call</a>, interim CEO Colette Kress said Vera Rubin brought in nearly $20 billion in its first quarter of shipments, the fastest ramp in Nvidia's history. She guided to $130 billion next quarter, plus or minus 3%, in a quarter with an extra week, and raised next year's growth forecast to about 75% from 70%.</p>
<p>The rest of the call was about what's missing. Per <a href="https://www.investing.com/news/stock-market-news/nvidia-earnings-beat-estimates-attention-turns-to-call-5034180">Reuters</a>, Nvidia opened by saying it wouldn't take questions on Huang's resignation and doesn't plan to reinstate him. Kress also said Nvidia sold $2.4 billion of licensed Hopper data center chips to China last quarter and is "no longer shipping" them, <a href="https://www.investing.com/news/stock-market-news/nvidia-stops-shipping-usapproved-ai-chips-to-china-5035204">Reuters reports</a>, without saying why or for how long. The forecast assumes no China data center revenue at all. The Neuron reports Huang has agreed to appear before House committees on Dec. 1, with Nvidia's general counsel the next day.</p>
<p>The market wasn't sold. <a href="https://finance.yahoo.com/markets/stocks/article/nvidia-stock-erases-earnings-pop-as-investors-face-life-after-jensen-huang-173547783.html">Yahoo Finance</a> has the stock down about 3.5% by midday after an almost 4% premarket pop, and quotes analysts who say chair Harvey Jones showed no urgency on naming a permanent CEO. At Wednesday's all-hands, <a href="https://www.wired.com/story/inside-nvidias-first-all-hands-without-jensen-huang-as-ceo/">WIRED</a> reports, Kress promised raises and more equity in December, months early, because pay was the top question among 700 submitted. Jones told staff the board won't look for a "Jensen clone" and cited Huang's "lack of candor."</p>

<h2 id="chips">OpenAI's models are designing chips</h2>
<p>OpenAI <a href="https://openai.com/index/advancing-chip-design-with-our-models/">published</a> the details behind its claim that its models help design chips. On Jalapeño, its first custom inference chip, engineers started using GPT-4o in early 2025. OpenAI estimates the model's changes cut the area of the logic cells by about 13% in the vector unit and 10% in the matrix unit. One multiplier redesign used about 15% less area and finished in one clock cycle instead of two. OpenAI says those gains held up on the real chip.</p>
<p>With AMD, OpenAI says its model rewrote the circuit code for AMD's flagship GPU and found up to 14% improvement in power, performance, and area over a design AMD's engineers had already tuned for years. OpenAI calls it about a year of progress in under five months. AMD has put some of the changes in a design already sent to manufacturing, and verified single-digit gains on blocks of its next flagship CPU. On two open-source RISC-V processor cores, GPT-6.2 Astra beat every earlier OpenAI model, and about doubled GPT-6 Astra's score on one. OpenAI is also training a model with Synopsys, the chip design software company, called GPT-Synopsys. OpenAI's <a href="https://x.com/OpenAI/status/2123100386638877054">post on X</a> was one of the most-liked AI posts of the day. These are OpenAI's numbers.</p>

<h2 id="java">AI found a hole in Java</h2>
<p>Calif, a security firm, <a href="https://calif.io/java4shell/">disclosed Java4Shell</a>, a memory bug in the Base64 decoder built into OpenJDK, the standard Java runtime. Base64 is the common way to write binary data as text, used in logins, file uploads, and network messages. A string of 64 letter A's followed by one equals sign makes the decoder write 62 bytes past the end of its buffer. Calif got remote code execution, with no login, on default setups of Keycloak, Jira, Confluence, JFrog Artifactory, Jenkins, and PingFederate. It rates 9.2 out of 10. OpenJDK posted an advisory and Oracle a patch Tuesday afternoon. Calif's post has the most points on the Hacker News front page today.</p>
<p>Researcher Quang Luong says he pointed Codex at the risky parts of the Java runtime, ignored about 20 minutes of bad findings, and then it turned up this one. Finding it took about an hour, the first exploit two more, and the tokens cost under $200. It only hits newer Intel Xeon and AMD Zen 4 or later chips, and the learn section explains why. NGINX had its own day too. <a href="https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities">Wiz</a> and four other teams separately found two critical no-login bugs in NGINX's HTTP/2 code, one dating back to 2015, with fixes from F5 out today.</p>

<h2 id="learn">Something to learn</h2>
<p>What does PPA mean, as in OpenAI's 14% gain on AMD's GPU? It stands for power, performance, and area, the three things every chip designer trades against each other. Power is how much electricity the chip burns. Performance is how fast it runs, usually the clock speed and how many cycles a job takes. Area is how much silicon it covers, and area is money: chips are cut from a fixed-size wafer, so a smaller design means more chips per wafer, and fewer of them ruined by a speck of dust. Designers write the chip as RTL, code in a language like SystemVerilog that says what data moves between storage slots on each tick of the clock. A tool then turns that code into a layout of standard cells, tiny pre-built pieces like a single logic gate or one bit of memory. That's what OpenAI means by "standard-cell area." When its model rewrote a multiplier to use 15% less area and finish in one cycle instead of two, it won on two of the three at once, which is rare. Usually a faster circuit is a bigger one.</p>
<p>And why does Java4Shell only hit some CPUs? Java checks every memory access, so a Java program can't write past the end of an array. But the Java runtime swaps some common functions, Base64 decoding among them, for hand-written machine code tuned to the exact CPU it's running on. These swaps are called intrinsics. On chips with AVX-512 VBMI, a set of instructions that handles 64 bytes at once, Java uses a special Base64 routine, and Java's safety checks don't run inside it. Intel Xeon since Ice Lake and AMD since Zen 4 have those instructions. Arm chips, like Apple's or AWS Graviton, don't, so they get the plain version and aren't affected. That's also why Calif's quick fix is a startup flag that turns the Base64 intrinsic off: Java goes back to the slower, checked code.</p>
