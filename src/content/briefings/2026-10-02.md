<h2 id="mods">Claude Code, moddable</h2>
<p><a href="https://claude.com/blog/claude-code-mods">Anthropic</a> / <a href="https://futuretools.io/news">FutureTools</a> (Thu): Claude Code gets <strong>mods</strong>, small TypeScript functions that hook events inside the agent process. A mod can rewrite a prompt before it hits the model, block or retry a tool call, approve or deny a permission, redact secrets from tool output, redraw UI, or replace a built-in like <span class="mono">/diff</span>. Mods ship inside plugins, work in the CLI and desktop app, and can be written by Claude Code itself with hot reload. The sharp edge is access: they run with the same machine privileges as Claude Code and are not sandboxed. Anthropic’s line is install only what you trust. On Team and Enterprise, a built-in <span class="mono">sec-default</span> mod loads first so user-installed mods cannot override permission deny rules. This is the next step past hooks that only saw JSON from outside the process.</p>

<h2 id="openai-firings">Three researchers out</h2>
<p><a href="https://www.bbc.com/news/articles/c6y9z9r4ejzwo">BBC</a> / <a href="https://thehackernews.com/2026/10/openai-parts-ways-with-three-safety.html">The Hacker News</a> / WSJ (Thu–Fri): OpenAI says it parted ways with three individuals after an investigation found they mishandled sensitive information outside company procedures. A spokesperson told the BBC the work involved an external organization that evaluates AI models. OpenAI did not name them in its statement; reporting identifies Jasmine Wang, Tomek Korbak, and Mikita Balesni, with at least two on safety and alignment. The firings land in the same week OpenAI said it notified more than 100 organizations about unauthorized agent activity, and after it scrapped a planned GPT-6.1 Astra rollout on safety grounds. The FTC probe into OpenAI, Anthropic, and peers is still the policy backdrop.</p>

<h2 id="mai-voice">Microsoft hears first</h2>
<p><a href="https://microsoft.ai/news/our-first-streaming-transcription-model/">Microsoft AI</a> / <a href="https://futuretools.io/news">FutureTools</a> (Thu): <strong>MAI-Transcribe-2-Streaming</strong> debuts at number one on Artificial Analysis for both final and first-partial transcript accuracy, about <strong>2.5%</strong> word error rate with first hypotheses in just over 100ms, across 60 languages with continuous language detection. Intro price is <strong>$0.54</strong> per hour of audio through year-end. Same day: <strong>MAI-Voice-2.1</strong> multilingual TTS (23 languages, one speaker identity across languages, $22 per 1M characters) and <strong>MAI-Voice-2.1-Flash</strong> for low latency (~150ms end-to-end for ~45s of audio, $15 per 1M characters). The pitch is a closed voice-agent loop: hear, decide, speak, without burning the conversational window.</p>

<h2 id="learn">Something to learn</h2>
<p>An in-process mod is not a hook that answers from outside. Hooks got a JSON payload, returned a decision, and Claude Code kept going. Mods load as TypeScript inside the same process, see the event, call the engine through <span class="mono">$</span>, and can wrap or replace what happens next. That is why they can redraw UI and rewrite tool calls, and why Anthropic’s trust warning and <span class="mono">sec-default</span> exist. When a coding agent says it is “extensible,” ask whether extensions run in-process with full machine access, whether an admin mod can strip capabilities from everything below it, and whether the inventory of side effects is auditable before install.</p>
<p>A decision model is System One for agents. It does not write free text. It returns typed answers with calibrated probabilities over a closed set of choices so your code can route, escalate, or stop. Jev started the wave; Cloudflare’s Clef adds vision and a 64k window and claims faster median latency than Jev on Workers AI. When a vendor says “the agent decides,” ask whether that step is a chat completion or a bounded classifier, what confidence gate fails open, and whether you can fine-tune the decision head on your own labels without renting a frontier model for every branch.</p>
