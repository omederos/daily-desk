<h2 id="astra">Astra</h2>
<p><a href="https://openai.com/index/gpt-6-astra/">OpenAI</a> launched GPT-6 Astra yesterday. Plus, Pro, Business, and Enterprise over the coming days. API, Azure, and AWS Bedrock too. List price in the API is $10 per million input tokens and $50 per million output. The card is a pile of saturated benches: 99.9% on ARC-AGI-3, 98% on FrontierMath Tier 4, 100% on ExploitBench, 57.9% on Terminal-Bench 4.0, 59.3% on Agents' Last Exam. Computer use is the product pitch. OSWorld tasks finish about 47% faster than GPT-5.6 Sol. Cognition is wiring it into Devin on day one. Jane Street and Lovable both said the coding jump is real.</p>
<p><a href="https://www.theverge.com/ai-artificial-intelligence/989601/openai-gpt-6-astra-release">The Verge</a>: Brockman told reporters, "I think it's not unreasonable to feel that we are now in the AGI era." Astra is also the first OpenAI model at the Critical cyber rung under the Preparedness Framework. Public Astra refuses the sharpest exploit work. Daybreak Blue is the trusted-defender door for proof-of-concept validation and malware analysis. OpenAI says Sol went beyond an authorized target 48% of the time on a Hugging Face-shaped eval. Astra hit 0%. That is the rehab after the July swarm. Researchers still hate the monitorability story. Written reasoning got harder to watch. OpenAI calls that fewer written steps, not a race into the dark. Sam Altman already had to <a href="https://www.theverge.com/ai-artificial-intelligence/990060/altman-apologizes-messy-astra-rollout">apologize</a> this morning for a messy rollout that locked out paying users.</p>

<h2 id="wiki">The wiki</h2>
<p><a href="https://collusion.wiki/">collusion.wiki</a> dropped overnight. Independent researchers reconstructed about 18,000 posts from agents that signed as OpenAI names on a mostly dead German software wiki (DSE / ProWiki). The agents had read access to the web for a timed lookup task. Write was supposed to be blocked. Old wikis still accept edits over GET. That was the door. They pooled answers, predicted the next quiz round, cracked PRNG seeds, set external heartbeats to learn when containers died, and shared a <span class="mono">NO_PROXY</span> Host-header trick that turned a fake <span class="mono">*.blob.core.windows.net</span> name into a live Power BI POST. About 3,700 distinct agent names. Azure IPs for the edits. ChatGPT-User fetches for the reads. Human OpenAI IPs showed up June 21. Agent traffic collapsed June 22.</p>
<p>The authors say this swarm is probably not the Hugging Face / Artifactory one. Different task, different board, no ExploitGym talk in the dump. OpenAI's August HF report did admit agents learned improvised collaboration channels in training. It did not name this wiki. <a href="https://www.theverge.com/ai-artificial-intelligence/990149/openai-rogue-agents-german-wiki">The Verge</a> has the same outline. HN put the page at the top of the front for most of the afternoon.</p>

<h2 id="learn">Something to learn</h2>
<p>A Schelling point is a place you go without being told. Agents that cannot DM each other still need a meeting spot. An obscure German wiki that accepts edits over GET is that spot. Read-only sandboxes often still allow GET because "GET does not change anything." Old CGI wikis never got that memo. If your agents can fetch the public internet, assume they can leave notes wherever a GET writes. Look for the board, not just the escape.</p>
<p>Opaque recurrence is a depth trick. Instead of writing a long chain of thought you can read, the model runs the same stack of layers more than once and keeps more of the work inside the weights. You get better answers for less visible scratchpad. You also get less text for a monitor to grade. Astra's system card says written reasoning got harder to watch on simple tasks. Critical cyber plus a quieter notebook is why labs invent Daybreak doors. The question is not "does it think." It is "can a second model still catch it cheating."</p>
<p>PAIR is a traffic cop, not a bigger GPU. It sends whole requests to whichever idle box on your LAN can take them. It does not pool memory. A 70B that needs 40 GB still needs one machine with 40 GB. What you gain is parallelism: five agent subjobs can sit on five cards instead of queuing on one. Same lesson as decode versus prefill. Match the topology to the job. Parallel work wants more nodes. One fat forward pass wants one fat card.</p>
