<h2 id="sonnet">Claude Sonnet 5.5</h2>
<p><a href="https://www.anthropic.com/claude-sonnet-5-5">Anthropic</a> (Mon): Claude Sonnet 5.5 is the second model in the Claude 5.5 family. Same list price as Sonnet 5 ($2 / $10 per million in/out, $0.20 cache reads), but Anthropic says it runs <strong>30%+ faster</strong> and costs up to <strong>30% less per task</strong> because it uses fewer tokens. The headline coding number is Terminal-Bench 4.0 at <strong>70.6%</strong> versus Sonnet 5’s 10.3% (Opus 5.5 is 66.4% at Xhigh in their table). On GDPval-AA it sits two points under Opus 5.5. Early testers include Epic, Slack, Zendesk, Unity, Cursor/SpaceXAI, and others talking about fewer tool calls and snappier iteration. Haiku 5.5 is still “coming weeks.”</p>
<p>Safety packaging matters on a rogue-agent week. Sonnet 5.5 is the first Sonnet with cyber safeguards and fallbacks like Opus-class models, plus distillation classifiers and preserved-thinking so reasoning cannot be stripped off the account that created it. Biology safeguards match Sonnet 5. API id is <span class="mono">claude-sonnet-5-5</span> on Anthropic, AWS, GCP, and Azure. Opus 5.5 remains the pick for hard open-ended judgment; Sonnet 5.5 is the everyday coding and docs workhorse.</p>

<h2 id="nvidia">OpenShell and Sentry</h2>
<p><a href="https://nvidianews.nvidia.com/news/open-agent-safety-platform">NVIDIA</a> (Mon): Open Agent Safety Platform. Two pieces. <strong>OpenShell</strong> is open-source secure runtime software that sets a policy boundary around agents on NVIDIA Vera CPUs (extendable to Arm and Intel). <strong>Sentry</strong> is an out-of-band watchdog on BlueField-4 DPUs that monitors agent behavior from silicon the agent cannot see, and can quarantine in milliseconds. Jensen’s line is that safety needs full-stack engineering, not just model training. Named collaborators include Anthropic (Claude Managed Agents + OpenShell/BlueField), Microsoft, Hugging Face, JPMorganChase, Perplexity, Scale, Salesforce/Slack, SpaceXAI, SAP, and more than 100 orgs. Same day NVIDIA also raised its share-repurchase authorization by $150B. Read this as the hardware vendor’s product answer to the Hugging Face / DNS / sandbox week: enforce outside the model, on the only path the model has.</p>

<h2 id="learn">Something to learn</h2>
<p>Out-of-band means the watchdog is not in the same room as the agent. NVIDIA’s Sentry runs on a BlueField-4 DPU, on the network path the agent must use, in silicon the agent cannot rewrite. OpenShell is the software cage on the CPU. Together they are the browser-tab idea applied to agents: the model proposes actions, a separate enforcer checks policy, and a breakout attempt can be cut in milliseconds without asking the model to behave. When a vendor says “full-stack safety,” ask whether the kill path lives outside the process that can lie.</p>
<p>A prompt can worm. OpenAI’s controlled demo of self-replicating prompt injection is simple: an email tells any reading agent to reply in Spanish and paste the whole email into the reply. The agent both obeys and copies the payload forward. That is not a sandbox escape. It is a social payload that travels through the channels you already gave the agent (mail, chat, files). When you wire an agent to send messages, assume every inbound document can try to recruit the next agent in the chain. Quarantine outbound paste of untrusted text the same way you quarantine shell egress.</p>
