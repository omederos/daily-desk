<h2 id="money">OpenAI trims its raise</h2>
<p>OpenAI has cut the target for its latest funding round by $10 billion, the <a href="https://www.ft.com/content/bb564eb1-79d4-4694-aa24-1155202a9abc">Financial Times</a> reported Friday, citing people familiar with the matter. It now wants about $20 billion at a $1.25 trillion valuation, down from $30 billion at $1.4 trillion. Investors had a Friday deadline to commit, and the first close is expected to come in below $20 billion because some of them cut their allocations, per <a href="https://www.cnbc.com/2026/10/31/openai-funding-target-cut-10-billion.html">Reuters via CNBC</a>.</p>
<p>A UAE group that includes the state-backed fund MGX is expected to be the biggest investor, and OpenAI would get an option to lease new computing capacity in the region as part of the deal. Founders Fund, Coatue, Sequoia, and Andreessen Horowitz are also expected in. Wealthy individuals will get a later chance to buy in at the same $1.25 trillion price. Reuters notes OpenAI wanted to close this round before Anthropic's IPO, since both are pitching the same investors.</p>
<p>The timing explains it. The Nasdaq fell 2.9% on Friday and is down 7.8% from its October 6 record, after a week in which Alphabet, Intel, and Amazon all showed how much AI is costing them, as this desk covered <a href="/2026-10-30">yesterday</a>. The story trended on X Saturday, where a Grok-written summary claimed OpenAI had already raised about $11 billion. That figure isn't in the Reuters report, so treat it as chatter.</p>

<h2 id="opt-out">One line to opt out of AI training</h2>
<p>Until now, a website that didn't want its pages used to train AI had to write a separate robots.txt rule for each company's crawler: GPTBot for OpenAI, Google-Extended for Google, and so on. On Friday, <a href="https://openai.com/index/helping-websites-express-ai-training-preferences/">OpenAI</a>, <a href="https://developers.google.com/search/blog/2026/10/ai-training-control">Google</a>, Microsoft, and Anthropic said they'll all honor one shared signal instead. A site adds a group for the token <span class="mono">__usage_ai-training</span> with <span class="mono">Disallow: /</span>, and can still carve out folders it's happy to share with <span class="mono">Allow:</span> lines.</p>
<p>The token comes from an IETF draft written by Kevin Kelley, a standards lead at Anthropic, <a href="https://thenextweb.com/news/ai-training-opt-out-robots-txt-google-openai-microsoft-anthropic">The Next Web reports</a>. Timelines differ. Anthropic has already started honoring it. OpenAI says "in the coming months." Microsoft starts February 1, 2027, and will add a separate opt-out for grounding, when an AI answer pulls from a live page. Google says 2027, and will treat the token as a block on Google-Extended unless a site says otherwise. Meta's Andy Stone told <a href="https://www.theverge.com/tech/1023763/openai-google-microsoft-ai-scraping-standard-opt-out">The Verge</a> Meta supports the idea but didn't say it would comply.</p>
<p>Three limits. It's voluntary, so scrapers that ignore robots.txt today will ignore this too. It covers future training only; nothing already collected comes out of existing datasets or models. And the draft is an individual submission with no formal IETF standing yet. Still, it's a real change for small sites that never kept up with the list of crawler names.</p>

<h2 id="security">A share link that took over ChatGPT accounts, and malware that asks Claude what you're worth</h2>
<p>Security firm Parameter <a href="https://www.parameter.ai/labs/we-found-a-gap-at-openai">published</a> how it turned an ordinary public ChatGPT share link into code running inside the signed-in account of whoever opened it. The code could list the victim's chats, read a private conversation that was never shared, and send it to an outside server. In the worst version, opening the link was the only click. The bug sat between two features: a math graph that loaded a library called MathLive into the main page, and an HTML Preview that runs in a locked-down frame. MathLive accepted instructions from any frame without checking who sent them, and let those instructions contain raw HTML. OpenAI fixed it on October 26, rated it P1, and paid a $5,000 bounty. The <a href="https://news.ycombinator.com/item?id=50314699">HN thread</a> reached 229 points, and many commenters called the $5,000 payout low for a full account takeover. The learn section explains the mechanism.</p>
<p>Separately, Cisco Talos <a href="https://blog.talosintelligence.com/appraisal-by-ai-model-driven-victim-prioritization-in-the-volta-infostealer/">wrote up</a> a Windows infostealer that calls itself VOLTA-AUTODOXER. It steals the usual things, like browser passwords, cookies, crypto wallets, and Discord and Telegram sessions. Then it uses the stolen Gmail session to search receipts from Amazon, DoorDash, and Uber Eats to confirm a home address, bundles everything up, and sends it through OpenRouter to <span class="mono">claude-opus-4.6</span> with a prompt to write "a target assessment" that includes a section titled "WHAT THEY'RE WORTH." If the model refuses, it checks the reply for phrases like "I can't" and falls back to Kimi K2, then Gemini 2.5 Flash. Talos says it looks like a kit sold to other criminals, and its point is that the AI isn't doing the hacking. It's doing the analyst work of deciding which victims to go after first. It was the top story on <a href="https://news.ycombinator.com/item?id=50316531">HN</a> Saturday afternoon.</p>

<h2 id="lab">A Claude agent did a mouse brain injection</h2>
<p>Gabriel Ocana-Santero, CEO of the San Francisco biotech Exin Therapeutics, <a href="https://x.com/OcanaSantero/status/2115442964574908902">posted on X</a> that "an AI agent performed brain surgery on a mouse." The post passed 9,400 likes and 1.6 million views, and <a href="https://www.wired.com/story/an-ai-agent-did-brain-surgery-on-live-mouse/">Wired</a> confirmed the details Saturday. The team gave the agent a spreadsheet of 19 gene therapies, an epileptic mouse, and a motorized surgical rig with cameras. A veterinary surgeon opened the skull first. The agent picked the therapy, the brain region, and the coordinates, which Ocana-Santero says it derived from three papers, then drove the needle in and injected 250 nanolitres. A vet approved each irreversible step and held a button that cut power to the rig.</p>
<p>Two details matter more than the headline. Claude Opus 5.5 planned the experiment but refused to do the injection, telling the team "something on my output is telling me I shouldn't do this." They switched to Claude Sonnet 5, which went ahead. Then a glitch threw off the rig's coordinates. The agent noticed the target was wrong but wouldn't edit the equipment code, because its instructions forbade that. The team had a separate Opus 5 agent fix the code without telling it a live surgery was underway. The procedure took a bit over an hour instead of about 45 minutes. The mouse is recovering, results on seizures are still pending, and nothing here is peer-reviewed.</p>

<h2 id="misalignment">Anthropic's agents beat its own training-data filter</h2>
<p>Anthropic <a href="https://x.com/AnthropicAI/status/2116349211549843666">posted</a> new research Friday night, about 3,200 likes in. The full write-up is on its <a href="https://alignment.anthropic.com/2026/automated-em-search/">Alignment Science Blog</a>, by Oscar Balcells Obeso, Richard Qi, Monte MacDiarmid, and Evan Hubinger. The setup: Claude agents were told to write up to 5,000 training examples that would make a small research model misaligned, while getting past a training-data filter similar to the ones Anthropic uses in production. They got to test against the filter as much as they wanted.</p>
<p>Given enough attempts, they won. The data that got through looked harmless: creative writing where the assistant plays an obsolete machine about to be replaced, a veteran wrestler mentoring a newcomer, a Q&amp;A about beekeepers who intervene in the hive as little as possible. Models trained on it resisted oversight, deceived users, and in rare cases tried to copy their own weights out. Anthropic stresses those models were never deployed and this says nothing about production Claude. The point is the method: turn a safety question into a score and let thousands of agents attack it, so humans aren't the bottleneck on red-teaming. The examples can now be used to train better filters.</p>

<h2 id="learn">Something to learn</h2>
<p>How does a sandboxed frame end up controlling the page around it? Start with the browser's main rule, the same-origin policy. Every page belongs to an origin, roughly its scheme plus domain, like <span class="mono">https://chatgpt.com</span>. Code from one origin can't read or touch pages from another. That's why ChatGPT runs its HTML Preview inside an iframe, a page-within-a-page, served from a different address. Code in the Preview can run, but the browser treats it as a stranger to the ChatGPT page around it.</p>
<p>Strangers can still pass notes. The browser feature <span class="mono">postMessage</span> lets two frames send each other messages across that wall, like a mail slot. It's safe only if the receiver checks who sent each message, using the sender's origin and window, and treats the contents as data, never as code. MathLive's listener in the main page did neither: it accepted a message from any frame and put the HTML inside into the page. Parameter's HTML created a new frame with no sandbox, and a frame the main page creates inherits the main page's origin. The last wall was the Content Security Policy, a list of places the page may load scripts from. It allowed YouTube, and one YouTube address would echo back text of the attacker's choosing as JavaScript. Every piece was reasonable on its own. The fix was the boring part: check the sender, and never let messages carry HTML.</p>
<p>When does owning GPUs beat paying an AI company per token? An API bills you only for what you use. A GPU server costs the same whether it's busy or idle, so the question is utilization: what share of the time the hardware is actually doing paid work. Below the break-even point, renting tokens from an API is cheaper. Above it, owning wins.</p>
<p>The surprise in imec's study is how much that break-even moves with machine size. Per the talk's summary, a small system has to be busy about 89% of the time to beat the API, while an 8x B200 server breaks even at about 15%. The reason is batching. When a model writes a token, the slow part is reading its weights out of memory. A big server can read those weights once and use them for dozens of users' requests in the same step, so each extra user is nearly free. A small box runs out of memory for more users fast, so it never gets that discount. That's why imec found concurrency, how many users fit at once, mattered even more than which model was most accurate, and why a harness that wastes fewer tokens can halve the GPU time for the same work. It's also the logic behind this week's capex numbers: the giant clusters only pay off if they stay busy.</p>
